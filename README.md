# Expense Tracker (Flutter)

A modern expense tracking mobile app scaffold using **Flutter + Riverpod + GoRouter + Hive**.

## Implemented features
- Login / Signup / Logout (local basic auth)
- Add / Edit / Delete transactions
- Income and Expense types
- Category support
- Dashboard with balance, income, expenses, transaction count
- Transaction list with search + category/type filtering
- Reports with pie and bar chart via `fl_chart`
- Dark/Light mode toggle
- CSV export
- Recurring transaction flag
- Offline-first local storage using Hive

## Run
```bash
flutter pub get
flutter run
```
